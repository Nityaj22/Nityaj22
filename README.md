I came to Purdue from Ahmedabad in 2023 as a pure CS major. First semester I took macroeconomics on the side and watched the Federal Reserve move entire markets with one rate decision. Econ became a minor, then a double major.

Since then every project has been some version of the same move: take a noisy system — the U.S. economy, the alcohol market, a Grand Prix — put real data on it, and find the decision hiding inside.
